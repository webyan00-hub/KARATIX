# Projet KARATIX

Ce projet est une application web moderne utilisant Vite, React, TypeScript et TailwindCSS.

## Technologies utilisées
- **Frontend**: React, Vite, TypeScript
- **Stylisation**: TailwindCSS, Shadcn/UI
- **Backend/Base de données**: Supabase
- **Gestionnaire de paquets**: Bun

## Instructions pour le test local
1. Cloner le dépôt.
2. Installer les dépendances : `bun install` ou `npm install`.
3. Lancer le serveur de développement : `bun dev` ou `npm run dev`.
4. Ouvrir `http://localhost:5173` dans votre navigateur.
